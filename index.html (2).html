Integration Assessment
Qualiphy API Review
Reviewed from api-docs.qualiphy.me — complexity, approach, and what Dulan actually needs to build.
LOW

Complexity: Low — This is very achievable.

Clean REST API. API key in JSON body — no OAuth, no token refresh, zero auth complexity. Core integration is one POST endpoint (POST /exam_invite) plus a webhook handler. They have a built-in test mode — Dulan can run the full end-to-end loop in sandbox using state "TE" without touching real patients. They also have a WordPress/WooCommerce plugin called Quidget — but since our form is custom-built, we'll use the API directly. Dulan can have a working prototype in sandbox within 2 days of getting API access (Monday).

What the API gives us
🔑
Simple Auth
API key in JSON body. No OAuth, no token expiry, no refresh flows. One env var, done.
⚡
One Core Endpoint
POST /api/exam_invite — send patient data, receive meeting_url + patient_exam_id. That's the integration.
🧪
Built-in Test Mode
Set state:"TE" + patient name "Test Approve" → approved. "Test Reject" → rejected. Full loop, no real patients.
🔔
Webhooks
Pass webhook_url in the invite. Qualiphy POSTs approval/rejection/dispatch status back to us. Standard pattern.
💊
GLP-1 Exams Already Exist
Semaglutide exam IDs visible in sample data (e.g. 2769, 3702). Dulan runs /exam_list to get our clinic's specific IDs.
🗺
State Routing Built-in
Pass state in the invite. Qualiphy routes to a licensed provider for that state. We build geo-restriction on our form, Qualiphy handles the rest.
📋
Pre-fill Patient Answers
Our custom form data can pre-populate Qualiphy's exam. Patient doesn't re-enter info — cleaner UX, lower drop-off.
📁
Attachment Upload
/exam_upload_attachment supports ID + lab uploads if required by the exam type.

Strategic Assessment
SWOT Analysis
Technology delivery lens — 10QBIT's perspective.

Strengths

  • Existing custom codebase — not building from scratch
  • Qualiphy API is simple, clean, well-documented — low integration risk
  • Qualiphy offloads clinical review, prescribing, and dispatch entirely
  • 10QBIT owns the full stack — no vendor lock-in
  • Cash-pay model — no insurance billing complexity
  • Buffer week (May 26–June 1) built into the plan as hard contingency

Weaknesses

  • Dulan has only 11 working days to complete all system work
  • Custom consultation form built without clinical input — competitor research only
  • No HIPAA-compliant infrastructure currently — full setup from day one
  • Qualiphy is a single point of failure for clinical approval and dispatch
  • No US brand equity, SEO, or patient base at launch

Opportunities

  • US GLP-1 telehealth market $30B+ and growing rapidly
  • Qualiphy API simplicity means integration risk is very manageable
  • Premium clinical positioning vs Ro, Hims/Hers tech-first approach
  • Buffer week protects quality — no pressure to ship with known issues
  • Replicable 10QBIT template for future US healthcare builds

Threats

  • FDA tightening GLP-1 telehealth rules mid-build
  • Qualiphy state coverage gaps limiting launch geography
  • HIPAA breach — catastrophic legal and reputational exposure
  • Warren / Sanj sign-off delays burning into buffer week
  • Scope creep from Warren or Sanj after build has started
